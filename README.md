## 🌟 Overview

**TalentPulse AI** is a production-ready, full-stack ATS platform that goes beyond simple keyword matching. It leverages:

- **Semantic similarity** via TF-IDF vectorization + cosine similarity
- **Job classification** using a pre-trained scikit-learn classifier fetched from HuggingFace
- **Explainable AI (XAI)** summaries generated by Groq's LLaMA 3.1 (or heuristic fallback)
- **Configurable weighted scoring** per job role — recruiters set their own priorities
- **PDF resume parsing** with automatic candidate name and location extraction

Recruiters can create job postings with custom JDs and scoring weights, then upload batches of PDF resumes for instant ranked analysis — all through a clean, sidebar-driven React UI.

## ✨ Key Features

| Feature | Description |
|---|---|
| 📄 **PDF Resume Parsing** | Extracts full text from PDFs using PyPDF2 with intelligent name & location detection |
| 🔍 **Semantic Matching** | TF-IDF cosine similarity between resume and job description |
| 🏷️ **Job Classification** | ML classifier assigns industry role labels to resumes |
| ⚖️ **Weighted Scoring** | 6-dimension score with recruiter-tunable weights per job |
| 🤖 **Explainable AI** | LLaMA 3.1 via Groq generates recruiter-facing strengths, gaps, and a verdict |
| 📊 **Radar Chart Visualization** | Interactive Recharts radar for score breakdown per candidate |
| 🗂️ **Job Management** | Create, store, and configure jobs with custom weights |
| 🗄️ **Analysis History** | Persist and replay results per job via MongoDB |
| 📑 **In-app PDF Viewer** | Inline PDF preview with a 70/30 split layout in the ATS page |
| 🔒 **Integrity Flag** | Auto-flags resumes as Genuine / Uncertain / Suspicious based on score |

## 🚀 Getting Started

### Prerequisites

- **Python** 3.10 or higher
- **Node.js** 18+ and **npm**
- **MongoDB** (local instance or [MongoDB Atlas](https://www.mongodb.com/cloud/atlas) URI)
- *(Optional)* **Groq API key** — for LLM-powered XAI explanations ([get one free](https://console.groq.com/))

---

### Backend Setup

```bash
# 1. Navigate to the Backend directory
cd Backend

# 2. Create and activate a virtual environment
python -m venv .venv
# Windows:
.venv\Scripts\activate
# macOS/Linux:
source .venv/bin/activate

# 3. Install dependencies
pip install -r requirements.txt

# 4. Configure environment variables
#    Copy the example below and create your own .env file
cp .env.example .env   # (or manually create .env)

# 5. Start the development server
uvicorn app.main:app --reload --host 0.0.0.0 --port 8000
```

The API will be available at `http://localhost:8000`.  
Interactive docs: `http://localhost:8000/docs`

---

### Frontend Setup

```bash
# 1. Navigate to the Frontend directory
cd Frontend

# 2. Install dependencies
npm install

# 3. Configure environment (optional — defaults to localhost:8000)
echo "VITE_API_URL=http://localhost:8000" > .env

# 4. Start the dev server
npm run dev
```

The app will be available at `http://localhost:5173`.

## 🧠 ML Pipeline

The scoring pipeline runs the following stages for each uploaded resume:

```
PDF Bytes
    │
    ▼
extract_pdf_text()       — PyPDF2 page-by-page extraction
    │
    ▼
clean_text()             — Remove URLs, non-ASCII chars, normalize whitespace
    │
    ├──► extract_candidate_name()    — Regex heuristic on first 12 lines
    ├──► extract_candidate_location() — City/State and City/Country pattern matching
    └──► extract_skills()            — Keyword set intersection with TECH_KEYWORDS
    │
    ▼
classify_text()          — TF-IDF + Logistic Regression (HuggingFace artifact)
    │
    ▼
compute_breakdown()
    ├── semantic      → cosine_similarity(resume_vec, jd_vec) × 100
    ├── skills        → |resume_skills ∩ jd_skills| / |jd_skills| × 100
    ├── experience    → regex years extraction, capped at 4 yrs = 100%
    ├── education     → keyword presence (bachelor/master/btech...)
    ├── projects      → keyword presence (project/built/developed...)
    └── alignment     → cosine_similarity(resume_probs, jd_probs) × 100
    │
    ▼
weighted_score()         — Normalized weighted sum across 6 dimensions
    │
    ▼
build_xai_with_groq()   — LLM: strengths, gaps, verdict (Groq / heuristic)
    │
    ▼
ResumeResult (ranked, returned in API response)
```

## 🔍 Explainable AI (XAI)

TalentPulse generates **recruiter-facing explanations** for every resume analysis.

### With Groq API Key (LLM mode)
- Sends score breakdown, top skills, and resume/JD excerpts to **LLaMA 3.1 8B Instant**
- Returns structured JSON: `strengths[]`, `gaps[]`, `verdict`
- Temperature set to `0.2` for deterministic, grounded output

### Without Groq API Key (Heuristic fallback)
- Rule-based: checks each breakdown dimension against thresholds
- Generates preset strength/gap messages accordingly
- No external API calls required

## 📊 Scoring Breakdown

| Dimension | Default Weight | Source |
|---|---|---|
| Semantic Similarity | 30% | TF-IDF cosine sim (resume ↔ JD) |
| Skills Match | 25% | Keyword intersection |
| Experience Match | 15% | Years of experience regex |
| Education Match | 10% | Degree keyword detection |
| Projects Relevance | 10% | Project keyword detection |
| Job Classification Alignment | 10% | Class probability cosine sim |

> 💡 **Recruiters can adjust all weights** per job posting via the Job Management page. Weights are normalized, so they don't need to sum to 1.0.

**Integrity Flags:**
| Score | Flag |
|---|---|
| ≥ 80 | ✅ Genuine |
| 50–79 | ⚠️ Uncertain |
| < 50 | 🚩 Suspicious |
